# 🔐 Py Secure Toolkit

A Python security toolkit providing reusable utilities and components for security-oriented development, testing, research, and educational purposes.

## ✨ Features

- 🐍 Python-based security toolkit
- 🧩 Modular and reusable components
- 🧪 Automated test suite
- 📚 Usage examples
- 📦 Standard Python package structure
- 🔒 Security-focused development

    ├── .gitignore
    └── README.md

## 🚀 Installation

### Clone the repository

Using SSH:

    git clone git@github.com:David-Caruelle/py-secure-toolkit.git
    cd py-secure-toolkit

### Create a virtual environment

#### Windows

    python -m venv .venv
    .venv\Scripts\activate

#### Linux / macOS

    python3 -m venv .venv
    source .venv/bin/activate

### Install the project

    pip install -e .

## 🧪 Tests

The test suite is located in the `tests/` directory.

Run:

    pytest

If pytest is not installed:

    pip install pytest

## 💡 Examples

Usage examples are available in the `examples/` directory.
